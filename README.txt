1. DESCRIPCIÓN GENERAL DEL PROYECTO
-----------------------------------------------------------------------

El presente proyecto consiste en el desarrollo de un sitio web informativo
orientado a estudiantes interesados en aplicar a programas de becas y
oportunidades académicas internacionales. El sitio reúne información
actualizada sobre distintos programas de movilidad, una experiencia personal
detallada del proceso de aplicación, historias reales de éxito y recursos
útiles para orientar a futuros aspirantes.

El sitio fue diseñado utilizando exclusivamente HTML5 y CSS3, aplicando
conceptos de maquetación web y haciendo uso de Flexbox y CSS Grid, cuidando
la estructura, el diseño y la correcta organización semántica de los elementos
de la página.

3. CONTENIDO DE CADA PÁGINA DEL SITIO
-----------------------------------------------------------------------

3.1 index.html – Página Principal
Incluye una presentación general del proyecto y su propósito educativo.
Proporciona accesos directos hacia las secciones principales: programas
de becas, experiencia personal, historia de éxito y soporte.

3.2 becas.html – Programas de Becas Internacionales
Contiene información esencial sobre diferentes oportunidades de estudio
en el extranjero, incluyendo:
    - Global UGRAD (Estados Unidos)
    - Fulbright (Estados Unidos)
    - Erasmus+ (Europa)
    - Scholarship Portal (Búsqueda general de becas)
    - DAAD (Alemania)

Cada sección presenta una descripción breve del programa y un enlace
directo a su sitio oficial para obtener información actualizada.

3.3 experiencia.html – Mi Experiencia de Aplicación
Describe de manera detallada mi experiencia al aplicar
a un programa internacional, incluyendo:
    - Preparación y envío del formulario en línea
    - Elaboración de ensayos y documentos solicitados
    - Entrevista en inglés
    - Examen TOEFL
    - Selección como finalista
    - Firma de términos y condiciones
    - Cancelación del programa por motivos presupuestarios
    - Reflexiones y aprendizajes personales

La página utiliza diseño con Flexbox y CSS Grid para presentar texto e imágenes de
forma equilibrada.

3.4 historias.html – Historias de Éxito
Presenta la historia de Jean Marco, un estudiante sobresaliente, destacando su logro
y su impacto académico. Incluye una estructura visual que mezcla texto e
imágenes sobre un fondo con degradado estilizado mediante Flexbox.

3.5 soporte.html – Preguntas Frecuentes y Consejos
Proporciona orientación general para futuros aplicantes:
    - Preguntas frecuentes sobre documentación, trámites y tiempos
    - Consejos clave para mejorar una aplicación a programas
      internacionales
    - Recomendaciones generales de preparación

-----------------------------------------------------------------------
4. DESCRIPCIÓN DEL ARCHIVO styles.css
-----------------------------------------------------------------------

El archivo styles.css contiene los estilos principales del sitio, entre
ellos:

    - Diseño con flexbox para acomodar imágenes y texto
    - Degradados lineales para secciones destacadas
    - Tipografías importadas desde Google Fonts (3 opciones para 
      experimentar):
        • Playfair Display
        • Noto Sans
        • Merriweather
    - Estilos reutilizables para botones, contenedores y navegación
    - Ajustes estéticos para títulos, espaciados y estructura visual

Se utiliza normalize.css para garantizar consistencia en los diferentes
navegadores.

-----------------------------------------------------------------------
5. NAVEGACIÓN Y ACCESIBILIDAD
-----------------------------------------------------------------------

El sitio incorpora un menú de navegación uniforme en todas las páginas,
permitiendo un acceso rápido y claro a las diferentes secciones. El footer
incluye enlaces adicionales hacia becas externas, soporte, categorías y
contacto del autor (mi persona).

La estructura del contenido prioriza:
    - Claridad visual
    - Lectura ordenada
    - Jerarquía tipográfica
    - Accesibilidad básica para usuarios en dispositivos móviles

-----------------------------------------------------------------------
6. TECNOLOGÍAS UTILIZADAS
-----------------------------------------------------------------------

    - HTML5 para la estructura semántica
    - CSS3 para el diseño visual
    - Normalize.css para estandarización de estilos
    - Google Fonts para la tipografía

No se utilizan librerías externas ni frameworks, lo cual permite un diseño
ligero, rápido y fácil de estudiar.
